# 声线采样室 · macOS Apple Silicon

适用于 M 系列芯片、macOS 14 或更新系统的本地声音采集应用。内置录音稿和运行环境，无需 Python、Node、浏览器、账号或网络连接。

## Mac 安装与使用

1. 在 [Releases](https://github.com/Bronc-X/voice-capture-macos/releases) 下载 `Voice-Capture-1.0.0-macOS-arm64.dmg`，无需登录 GitHub。
2. 打开 DMG，把 **Voice Capture** 拖到 **Applications（应用程序）**，再从应用程序打开。
3. 接好大疆麦克风，在“系统设置 → 声音 → 输入”中选中它；也可以用 Mac 内置麦克风。
4. 勾选声音授权，点击“连接麦克风”，在 macOS 弹窗中允许访问麦克风。
5. 录制、复听并点击“收下并继续”。至少收下 18 段后，分别导出合并 WAV 和 JSON 质量清单。保存位置由你选择。

**关闭前请导出。** 录音保留在当前窗口的内存里，不自动上传，也不自动存入磁盘。关窗或退出时会提示返回导出；强制退出或断电无法保留内存录音。

### 首次打开与签名状态

当前默认构建为 **ad-hoc 签名版，未做 Apple Developer ID 签名与公证**。这不影响内置运行环境，但下载后 macOS 可能拦截首次打开，不能承诺“下载后零提示双击运行”。

- 若提示无法验证开发者：先尝试打开一次，再到“系统设置 → 隐私与安全性”点击“仍要打开”。
- 若系统提示应用已损坏且不给放行入口：先核对下载文件的 SHA-256 与 Release 的 `SHA256SUMS.txt`。确认是本仓库的包后，可仅移除这个应用的下载隔离标记：`xattr -dr com.apple.quarantine "/Applications/Voice Capture.app"`，再打开。无需关闭系统 Gatekeeper。
- 要消除这一步，需用自己的 Apple Developer 证书重新构建并完成公证；见 [Mac 构建说明](docs/MAC_BUILD.md)。

### 麦克风与文件保存

- 曾拒绝麦克风：在“系统设置 → 隐私与安全性 → 麦克风”打开 Voice Capture 的开关，再退出并重开应用。
- 换了输入设备：先在系统声音设置中选择，再点击应用里的“连接麦克风”重新连接。
- 保存窗口取消：录音仍在当前窗口中，可重新导出。
- 保存失败：检查磁盘空间、文件夹权限，换一个位置重试。
- 本程序不包含声线克隆或合成引擎；它负责采集、复听与导出声音样本。

## 验证与开发

```sh
npm ci
npm test
npm run test:desktop
npm start
```

GitHub Actions 在 Apple Silicon Mac 上生成 DMG / ZIP，校验架构与签名结构，从 DMG 复制应用后启动测试。测试使用 Chromium 模拟麦克风，覆盖录音、播放、18 段合并导出、WAV/JSON 对齐、取消/失败后重试、权限拒绝与退出保护；不能替代真实大疆设备、系统权限弹窗或下载隔离状态的人工验收。

构建用 `npm run dist:mac`，需要 macOS；安装后的应用不需要这些开发命令。源码、构建版本与安装包校验信息见对应 Release。

## 原有 Windows 网页版

这是三期企业 AI 播客数字旁白的本地声音采集页。它只采集用户本人明确授权的声音，不从会议录音克隆参会者，也不把声音自动上传到任何服务。

### 启动

1. 把大疆麦克风或其他麦克风接到电脑，并在 Windows 中选为输入设备。
2. 在本目录右键打开 PowerShell，运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start_voice_capture.ps1
   ```

3. 浏览器打开后，勾选声音授权边界，点击“连接麦克风”。
4. 按页面顺序录制 20 段。每段都先复听；有口误、喷麦、混响或环境声就重录。
5. 最后同时导出：

   - `OWNER_voice_dataset_..._48k_pcm16_mono.wav`
   - `OWNER_voice_dataset_..._manifest.json`

两个文件放在同一文件夹。浏览器刷新或关闭后，内存里的录音不会保留，所以请在离开页面前完成导出。

## 采集标准

- 推荐 10–15 分钟有效语音；页面共 20 段，至少 18 段才开放导出。
- 浏览器导出为 PCM WAV，48 kHz、16-bit、mono。若同时用大疆设备原生录制，可保留一份 48 kHz / 24-bit 干声作为更高规格母本。
- 关闭降噪、自动增益和回声消除；页面会主动请求这些设置，但浏览器和声卡可能忽略，最终仍需耳机复听。
- 峰值建议在 −12 至 −3 dBFS。削波必须重录；音量偏低、口腔音、风扇声和房间混响需要人工判断。
- 正常说话，不模仿任何主持人或参会者。数字声线要保留用户本人的自然表达。

## 后续流程

1. 检查 WAV 与 JSON，剔除质量不合格段落。
2. 用其中的无敏感内容段落建立用户本人声线。
3. 先合成 60–90 秒试音，让用户确认音色、语速、停顿、英文缩写和人名发音。
4. 确认后，按 v1.2 的旁白 allowlist 批量生成三期：只处理 `[主持*]` 文本；`[CLIP]`、会议原声、证据行、时间码和制作说明全部排除。
5. 所有成片标记“合成旁白”，保存文本哈希、引擎/模型版本、生成时间和撤回记录。

## 设计方向

界面采用“编辑部录音单”式的 editorial utilitarian 方向：纸张、黑墨、朱红录音印章和磁带刻度构成单一视觉语言。DFII 为 15（影响 4 + 场景适配 5 + 可行性 4 + 性能 4 − 一致性风险 2）。最明显的识别锚点是左侧磁带轨道与页面上的 `REC / OWNER ONLY` 印章，而不是常见的紫色 AI 控制台。
